## 🎯 The Basic Workflow (30 seconds)

### Create a Group

1. Click **"Add Student"**
2. Fill in student info
3. Scroll to **"Groups / Classes"**
4. Type group name: `Group A`
5. Press **ENTER** (important!)
6. Click **"Create Student"**

**Result:** Group A created with that student assigned

### Manage Groups

1. Find student card
2. Click **✏️ pencil icon**
3. Check/uncheck groups
4. Click **"Save"**

**Result:** Student groups updated

## 🐛 Something Not Working?

### Check These First

1. **Can't find Groups section?**

   - Make sure you scrolled down in the Add Student form
   - It's below Subject, above Parent Contact

2. **Group name not being added?**

   - Are you pressing ENTER (not Tab)?
   - Is there text in the input?
   - Try clicking the input first, then typing

3. **Changes not showing after saving?**

   - Wait 1-2 seconds
   - Refresh page (F5)
   - Check browser console (F12) for errors

4. **Can't see group filter tabs?**
   - Go back to Students page
   - Look below the search box
   - They appear once you have students with groups
