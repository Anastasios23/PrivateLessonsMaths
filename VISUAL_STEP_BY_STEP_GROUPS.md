## 🎯 Key Takeaways

| Action             | How                                    | Result                           |
| ------------------ | -------------------------------------- | -------------------------------- |
| Create Group       | Add student + type group name + ENTER  | Group created when student added |
| Add to Group       | Same group name when adding student    | Student joins group              |
| Multiple Groups    | Add multiple group names, each + ENTER | Student in all groups            |
| Filter by Group    | Click group tab below search           | See only students in that group  |
| Edit Groups        | Click ✏️ on student card               | Modify student's groups          |
| Move Student       | Uncheck old group, check new group     | Student moved to new group       |
| Add to Extra Group | Check new group without unchecking old | Student added to extra group     |
